# سایت سه‌بعدی با Three.js

یک وب‌سایت سه‌بعدی ساده و زیبا ساخته شده با HTML و کتابخانه Three.js.

## ویژگی‌ها
- مکعب اصلی درخشان با چرخش خودکار
- مکعب‌های کوچک در حال گردش
- ذرات شناور
- کنترل کامل با موس (چرخش و زوم)
- طراحی تاریک و مدرن

## نحوه اجرا
فقط فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages
1. این ریپازیتوری را Fork یا Clone کنید
2. به Settings → Pages بروید
3. Source را روی `main` branch تنظیم کنید
4. سایت شما در آدرس زیر در دسترس خواهد بود:
   `https://USERNAME.github.io/REPO-NAME`

## تکنولوژی‌ها
- HTML5
- CSS3
- Three.js (r160)
- OrbitControls
